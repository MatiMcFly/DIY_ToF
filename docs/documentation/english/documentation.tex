\newcommand{\vAbstract}{
    This project work deals with the development of a \acrfull{diy} system for optical \acrfull{tof} distance measurement.

    A \acrfull{tdc} is used to precisely measure the signal propagation time. For test purposes,
    a second \acrshort{tdc} is used, which is operated purely electrically to determine the length of different
    copper cables.

    The work includes the development of the hardware, including laser drivers, photodetectors and
    transimpedance amplifiers, as well as the implementation of the firmware for signal evaluation. Simulations and measurements
    were carried out to optimize accuracy and minimize interference.

    The electrical measurements show that the \acrshort{tdc} achieves a temporal resolution in the range of several tens of
    picoseconds. This allows cable lengths to be determined to within a few centimeters.

    The optical measurements show that a rough distance measurement up to about 30 cm is possible when a mirror is used as a
    target is used. In order to measure the distance to a wall, further improvements to the demonstrator are necessary.
}
